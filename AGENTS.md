# AGENTS.md - Praxis

An [agents.md](https://agents.md) standard file (Linux Foundation / Agentic AI Foundation) - canonical instructions for AI agents working with this repository. Read natively by Cursor, Codex (OpenAI), Jules (Google), Devin / Windsurf, Aider, Amp, Factory, GitHub Copilot.

## Project goal

**Praxis** is an open line of **practical guides for law firms**, published by [MateMatic](https://matematicsolutions.com). Knowledge about safe use of AI in a law firm should be a common good - this repo is its home.

Two formats:

- **Maps** - live, searchable inventories of tools and resources (e.g. a map of Polish LegalTech AI).
- **Handbooks** - procedural step-by-step guides with checklists and downloadable artifacts.

First handbook: **PX/03 - Zero-cloud stack for law firms** ([przewodniki/px03-stack-zero-cloud/](./przewodniki/px03-stack-zero-cloud/)).

## MateMatic context (HARD CONSTRAINTS)

The repo is run by [MateMatic Solutions](https://matematicsolutions.com). Praxis has three editorial principles ([README.md](./README.md)):

1. **Active, not static** - these are working tools, not frozen PDFs.
2. **Subjective, not objective** - with explicit MateMatic commentary and perspective. No pretense of an "objective ranking".
3. **Live, not frozen** - versioned, developed with reader feedback.

## Build and test

The repo is plain Markdown. No compilation.

"Test" = a manual walkthrough of the handbook against **2 law firm archetypes** (solo practitioner + 10-person team) - if any step is not executable, the handbook is bad.

The web version is generated by the `www-matematic` repo (private, deploys to matematicsolutions.com).

## Writing rules (CRITICAL)

- **Polish language, MateMatic tone** - precise, calm, no sales marketing. See the `bw_style` feedback in operational MEMORY.
- **Marko-pl double round** before every commit (charges -> fixes -> "ok") - ALWAYS before publishing.
- **Humanizer-pl** for the final polish (anti-AI-slop).
- **No em-dash** - use a plain hyphen `-`. Never `—` or `–`.
- **No Polish characters in commit messages** - organization convention.
- **Cite sources** - legal act (with CELEX for EU), tool (with a link to the repo/site), study (with a DOI or URL).
- **Executable checklists** - every step has a "yes/no" answer, no "think about it".

## What NOT to do (hard rules)

- **DO NOT feign objectivity** - Praxis is subjective by definition. Write "MateMatic recommends X because Y" instead of "the best tool is X".
- **DO NOT insert a sales pitch for Patron / lpm-pl / matematic-readiness** in the handbooks. If a MateMatic product is a natural example - link it, but as neutrally as the competition.
- **DO NOT copy external content 1:1** without attribution - CC BY-SA requires attribution.
- **DO NOT commit real law firm / client names** in examples.
